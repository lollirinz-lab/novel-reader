# เสียงหวานนิยาย (PWA Audio Novel Reader) 📖🎧

เว็บแอปอ่านและฟังนิยายเสียงภาษาไทยระดับพรีเมียม รองรับทั้งบนคอมพิวเตอร์ และมือถือ **iOS (iPhone/iPad)** และ **Android** 

---

### ✨ ฟังก์ชันเด่น (Features)

1. **เสียงพากย์นุ่มนวล สมจริงที่สุด (Microsoft Edge Neural TTS):**
   - **เสียงผู้หญิง:** `เปรมวดี` (เสียงหวาน นุ่มนวล เว้นวรรคหายใจสมจริง ฟังเพลินไม่ล้าหู)
   - **เสียงผู้ชาย:** `นิวัฒน์` (เสียงอบอุ่น ชัดเจน ทรงพลัง)
   - แคชเสียงอัตโนมัติบนเครื่อง เปิดซ้ำได้ทันทีไม่ต้องโหลดใหม่
   - ระบบ **Prefetch** ทยอยแปลงย่อหน้าถัดไปล่วงหน้า เสียงจึงไหลลื่นไม่สะดุด

2. **รองรับไฟล์นิยายทุกประเภท:**
   - **.EPUB** (ถอดรหัสบท สารบัญ และจัดย่อหน้า)
   - **.PDF** (สกัดข้อความ กรองหัว/ท้ายกระดาษออก)
   - **.TXT** (รองรับทั้ง UTF-8 และ Windows-874 ภาษาไทย)
   - **.DOCX / .DOC** (แปลงหัวข้อและย่อหน้าอัตโนมัติ)
   - **คลังนิยายในเครื่อง:** ตรวจจับและดึงนิยายที่เคยเก็บไว้ในโฟลเดอร์มาให้อ่านได้ทันที 9 เรื่อง!

3. **ใช้งานบนมือถือแบบเต็มจอ (PWA App):**
   - เปิดผ่าน Wi-Fi เดียวกัน เข้าได้ทันทีจากทั้ง iPhone และ Android
   - **iOS (Safari):** กดปุ่ม Share ➡️ เลือก **"Add to Home Screen"**
   - **Android (Chrome):** กดสามจุด ➡️ เลือก **"Install App"**
   - รองรับ **เล่นเสียงในพื้นหลัง (Background Audio)** และคุมการเล่นผ่าน **Lock Screen / Dynamic Island / Apple Watch** ได้เต็มรูปแบบ

4. **เครื่องเล่นเสียงและโหมดอ่าน (Audio Player & Reader):**
   - ปรับความเร็วเสียงอ่าน: `0.8x`, `1.0x`, `1.25x`, `1.5x`, `1.75x`, `2.0x`
   - กรอหน้า-หลัง 15 วินาที
   - แตะย่อหน้าใดๆ เพื่อให้กระโดดไปอ่านย่อหน้านั้นทันที
   - ตัวจับเวลาปิดอัตโนมัติ (Sleep Timer): 15, 30, 45, 60 นาที หรือปิดเมื่อจบตอน
   - โหมดถนอมสายตา 4 ธีม: กระดาษถนอมสายตา (Sepia), โหมดมืด (Dark), ดำสนิท (OLED), และโหมดสว่าง (Light)
   - ปรับขนาดตัวอักษรเนื้อเรื่องได้อิสระ

---

### 🚀 วิธีเปิดใช้งาน (How to Run)

เปิด Terminal แล้วสั่ง:
```bash
cd "/Volumes/Vora M2/_Antigravity/_เก็บนิยาย/_Read Novel"
./start.sh
```
หรือรัน:
```bash
./venv/bin/python run.py
```

เมื่อรันแล้ว:
- **เปิดบนคอมพิวเตอร์:** [http://localhost:8000](http://localhost:8000)
- **เปิดบน iPhone / Android:** สแกน QR Code ที่แสดงบนหน้าจอ หรือพิมพ์ URL: `http://<IP-เครื่องของคุณ>:8000` (เช่น `http://192.168.1.102:8000`)
